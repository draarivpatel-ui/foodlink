# FoodLink demo video

Narrated 1080p walkthrough of the post-revamp UI (`e37fcf0`): the
collision-aware dispatch map with stop badges on their nodes, the Dispatch
outcome ledger (183 kg rescued, 464 servings, 0 kg spoiled, 108.9 kg CO2e
at the corrected EPA WARM v15 low-end factor of 0.595 kg per kg, tightest
cold-chain margin, exact solver), shelf-life triage with live spoils-in
windows under the FDA four-hour TCS cap, household box allocation with
hard dietary constraints, the storm scenario switch, the Spanish toggle,
manifest and data tabs, the 29 in-page self tests, and the live
verification card. Everything below is produced locally and repeatably;
no API keys, no network calls, no signed-in browser.

## Files

| File | Role |
| --- | --- |
| `demo/narration.txt` | Voiceover source. One sentence per line, blank line between paragraphs. |
| `demo/steps.json` | The drive plan. `at` steps pin actions to narration marks (`"mark": "2.1"` = paragraph 2 sentence 1). |
| `demo/timing.json` | Measured per-sentence start/duration from the synthesized audio. Regenerated by `synth`. |
| `demo/narration.wav` | Assembled voiceover (Aariv OmniVoice clone, `mlx-community/OmniVoice-bf16`, `voice-ref.wav`, seed 1, 24 kHz mono). |
| `demo/captions.ass` | Lower-third captions burned into the video. |
| `demo/foodlink-demo.srt` | Companion captions file for upload. |
| `demo/test-proof.txt` | Real outputs of `node --test tests/` and the honesty harness, captured during `capture` and shown on screen near the end. |
| `demo/proof.html` | The on-screen verification card rendered from `test-proof.txt`. |
| `demo/foodlink-demo.mp4` | The finished video. |
| `scripts/record-demo.mjs` | The whole pipeline: `synth`, `capture`, `check`, `all`. |
| `scripts/omnivoice_say.py` | Batch OmniVoice helper (loads the model once per job; per-unit seed override for retakes). |
| `scripts/serve.mjs` | Zero-dependency static server used by `capture`. |

## Reproduce

Set `OMNIVOICE_REF` to the reference clip (with `voice-ref.txt` beside it) and
`FOODLINK_OMNI_PY` to the mlx-audio Python. The rendered `narration.wav` and
`foodlink-demo.mp4` are build outputs kept out of git; the published video is
hosted with the submission.

```bash
npm run demo:synth     # narration.txt -> narration.wav + timing.json + captions
npm run demo:capture   # proof + serve + headless Chrome drive -> demo/foodlink-demo.mp4
npm run demo:check     # ffprobe report
```

`synth` writes one OmniVoice batch job for the missing sentences and runs
it once under `nice -n 19`, so a re-run only synthesizes what changed.
`capture` first writes `demo/test-proof.txt` from live command output
(845 Node tests plus the station honesty harness) and refuses to record
unless every check is green, then serves the repo on an ephemeral port and
drives the app in a throwaway headless Chrome (empty profile, ephemeral
CDP port, real mouse and key events, a visible drawn cursor). The
screencast resamples to a constant 30 fps and muxes the narration plus
burned captions in one ffmpeg pass (`yuv420p`, `color_range=tv`,
`+faststart`, `aac` 24 kHz). All temp files live in `FOODLINK_DEMO_TMP`
(or a fresh `/tmp/omnivoice-l148-*` dir) and are deleted on exit.
Downloads are denied at the browser level and the drive aborts if the
page ever leaves the demo origin.

## Honesty note

The 108.9 kg CO2e figure is the corrected EPA WARM v15 food-donation
low-end factor (0.54 MTCO2e per short ton, about 0.595 kg per kg
delivered), not the retired 2.5 value. Every number on screen is computed
by the app during the drive; the proof card quotes the test run that
happened in the same session.
